# Academic Writing Skills

Reusable academic-writing skills for evidence-grounded Discussion writing.

## Contribution-led Discussion

[Skill instructions](skills/contribution-led-discussion/SKILL.md) support drafting, revision, and checking of qualitative and practice-based academic Discussion sections. They preserve contribution-led reasoning, participant context and short quotations, explicit cross-case analysis, theoretical positioning, and concrete researcher-designer decisions.

The skill includes a separate originating-PhD context reference and a checklist covering all 30 finalized writing requirements. English/Chinese paragraph checking is supported when requested.

### Use

Copy the complete `skills/contribution-led-discussion` folder into your assistant's skills directory (for Codex, `~/.codex/skills/`). Then invoke:

```text
Use $contribution-led-discussion to revise this Discussion using the attached
Findings, design records, and literature. Provide corresponding English and
Chinese paragraphs so I can check the argument.
```

Supply the relevant source material. The skill does not substitute its illustrative PhD cases for another project's evidence or invent missing quotations, references, or design decisions.
